 # پروژه طراحی سایت فروشگاه آنلاین

این اولین پروژه من در توسعه وب است که مرحله به مرحله در حال تکمیل شدن می‌باشد.

# تکنولوژی‌های استفاده شده
- **بک‌اند:** Flask (Python)
- **دیتابیس:** MySQL (مدیریت شده با phpMyAdmin)
- **فرانت‌اند:** HTML, CSS, JavaScript

## وضعیت فعلی پروژه
در حال حاضر بخش‌های زیر با موفقیت انجام شده و زیربنای پروژه آماده است:
- طراحی ساختار اولیه صفحات
- استایل‌دهی پایه (CSS)
- راه‌اندازی اتصال به دیتابیس
